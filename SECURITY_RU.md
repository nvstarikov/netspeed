# Политика безопасности

## Поддерживаемые версии

Обновления безопасности выпускаются только для последней мажорной ветки.

| Версия | Поддержка |
|--------|-----------|
| 1.0.x  | ✅        |

Если у вас старая версия — обновитесь через лаунчер (автообновление при запуске) или скачайте последнюю сборку из [GitHub Releases](https://github.com/nvstarikov/netspeed/releases/latest).

---

## 🛡️ Сообщить об уязвимости

**НЕ создавай публичный Issue для уязвимостей.** Публичный отчёт может навредить пользователям до выхода патча.

### Как сообщить правильно

**Способ 1 — email (предпочтительный):**

Напиши на **security@stargrd.ru** с темой:

Опиши:
- Тип уязвимости
- Шаги воспроизведения
- Возможное влияние
- Предлагаемое решение (если есть)

**Способ 2 — приватный канал на форуме:**

Зарегистрированные пользователи могут отправить личное сообщение **команде безопасности СТАРГРАДД** на [форуме](https://stargrd.ru/forum/).

### Что мы обещаем

- Подтвердим получение за **48 часов**
- Держим в курсе статуса исправления
- Укажем тебя в благодарностях (если не против)

---

## 🚫 Что НЕ считается уязвимостью

Следующее — ожидаемое поведение, а не проблемы безопасности:

- **Отсутствие цифровой подписи `.exe`** — планируется в будущих релизах
- **Сообщения антивируса на неподписанные сборки** — нормально для инди-проектов
- **Недоступность зарубежных узлов (Hetzner, Tele2) с российских каналов** — DPI/блокировки, не баг
- **Требование прав пользователя** (админ не нужны для запуска) — архитектурное решение
- **Отсутствие поддержки Windows 7/8/Vista** — устаревшие платформы

---

## 🔐 Что мы делаем для безопасности

NetSpeed спроектирован с минимальной поверхностью атаки:

- **Нет телеметрии** — ни один байт не покидает ваш компьютер
- **Нет облачной синхронизации** — все замеры хранятся локально в `netspeed_history.md`
- **Нет автоотправки** — ничего не уходит на серверы СТАРГРАДД автоматически
- **Нет зависимости от внешних API для основных функций** — замеры идут через публичные зеркала
- **Распространение только через официальный лаунчер** и GitHub Releases — никаких сторонних зеркал

## 📋 Если заметили подозрительное

Если поведение программы кажется странным (неожиданная сетевая активность, запись файлов вне папки с утилитой, странные исходящие соединения):

1. **Отключите машину от сети** — изолируйте её
2. **Зафиксируйте наблюдения** — скриншоты, команды, время
3. **Сразу свяжитесь с нами** — security@stargrd.ru
4. **Не публикуйте в открытых источниках**, пока мы не подтвердим

Мы относимся к каждому отчёту серьёзно.
